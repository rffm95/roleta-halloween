# 🎃 Roleta de Halloween — Cheers O Bar

Versão de Halloween da roleta do Cheers O Bar para a TV do bar.

- Mesmos prémios e probabilidades da roleta original: 3 × "3 finos", 2 × "1 fino", 1 × "Régua" e 6 × "Tenta outra vez".
- Qualquer tecla do comando ou clique faz girar; outra tecla fecha o resultado.
- Ecrã fixo 1440×900 que se ajusta a qualquer TV; build compatível com browsers antigos de Smart TV.
- Efeitos de som sintetizados (sem ficheiros). Para desligar o som abre o link com `?som=0`.

## Correr localmente

```
npm install --legacy-peer-deps
npm run dev
```

O deploy para o GitHub Pages é automático a cada push para `main` (`.github/workflows/deploy.yml`).
